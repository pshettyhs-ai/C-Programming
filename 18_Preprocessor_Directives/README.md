# 18_Preprocessor_Directives — Preprocessor Directives

> **Author: Pavan Shetty H S**

## 📋 What This Chapter Covers

The preprocessor runs before the compiler and handles #include, #define, and conditional compilation. I cover safe macro writing, include guards, the stringify and token-paste operators, and predefined macros like __FILE__ and __LINE__.
