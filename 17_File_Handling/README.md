# 17_File_Handling — File Handling

> **Author: Pavan Shetty H S**

## 📋 What This Chapter Covers

Programs usually need to save and load data. This chapter covers opening, reading, and writing text and binary files, using fseek for random access, and building a simple record-based file database using structs.
