# 14_Unions — Unions

> **Author: Pavan Shetty H S**

## 📋 What This Chapter Covers

A union is like a struct, but all members share the same memory. Only one member holds a valid value at a time. I explain tagged unions for safe usage, type punning, endianness detection, and when unions save memory over structs.
