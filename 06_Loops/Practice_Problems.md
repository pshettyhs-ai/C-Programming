# Practice Problems — Loops

> **Author: Pavan Shetty H S**
>
> Problems I worked through while learning this chapter. Arranged from easy to hard.
>
> **My tip:** For every loop you write, ask: what is the loop invariant? What is always true before and after each iteration?

---

## 🟢 Easy

**P1.** Write a program that demonstrates all core concepts of Loops with clear, labelled output.

**P2.** Write 5 small focused programs — one per key feature. Keep each under 20 lines.

**P3.** Make P1 interactive: read values from the user instead of hardcoding them.

**P4.** Write a program that tests edge cases: zero, negatives, maximums, empty input.

**P5.** Display results from Loops in a formatted table using printf width and precision.

---

## 🟡 Medium

**P6.** Combine Loops with structs to build a small record-keeping program.

**P7.** Read input from a file, process it using Loops concepts, write output to another file.

**P8.** Organise your best code into reusable functions with clear prototypes and documentation.

**P9.** Add thorough error handling and input validation to one of your earlier programs.

**P10.** Implement a sorting or searching algorithm that directly exercises Loops concepts.

---

## 🔴 Hard

**P11.** Build a complete small program using only Loops and earlier chapters. Plan on paper first.

**P12.** Optimise a solution you already wrote — document the time complexity before and after.

**P13.** Write a "common mistakes showcase": show the buggy version and the correct version side by side, with explanation comments.

**P14.** Rewrite your best program from this chapter to production quality: error handling, validation, clean decomposition, educational comments throughout.

---

## 💡 Challenge

**P15.** Solve at least two problems on HackerRank or LeetCode using Loops concepts. Paste the problem URL as a comment at the top of your solution file.
