# 13_Structures — Structures

> **Author: Pavan Shetty H S**

## 📋 What This Chapter Covers

Structures let you group different types of data under one name. I cover declaration, initialization, nested structs, arrays of structs, passing structs to functions efficiently, and the memory layout including padding and alignment.

## 🎯 Learning Goals

By the end of this chapter you should be comfortable with every core concept, be able to write correct programs without looking at a reference, and confidently answer interview questions on this topic.
