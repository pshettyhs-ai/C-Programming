## 📋 About This Section

This is my personal interview preparation folder. I collected questions from friends, from placement drives I attended, and from online resources — then wrote answers in my own words so I actually understood them rather than just memorised them.

If you are preparing for placements, use this alongside the Interview_Questions.md in each chapter folder.

## 📂 Files

| File | What is inside |
|------|---------------|
| `Top_100_Questions.md` | 100 most commonly asked C interview questions with detailed answers |
| `MCQ_Practice.md` | 75+ multiple choice questions with answer key |
| `Placement_Guide.md` | Company-wise question patterns, 30-day plan, and last-minute checklist |

## 🎯 How I Used This Folder

1. Read through all Top 100 questions once without looking at answers
2. Wrote my own answers before checking
3. Did the MCQ practice timed (1 minute per question)
4. Revisited every question I got wrong after 2 days

The spacing and active recall made a big difference.
