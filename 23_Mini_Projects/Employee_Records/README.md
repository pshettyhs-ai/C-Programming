# Employee_Records

> **Author: Pavan Shetty H S**

## 📋 About This Project

An employee record management system with salary calculation, department filtering, and performance reports. Demonstrates dynamic memory allocation with structs.

## 🔨 Compile and Run

```bash
gcc Source_Code/main.c -o program
./program
```

## 💡 Concepts Used

Dynamic memory (malloc/realloc), structs, sorting, file I/O

## ⭐ Difficulty: ⭐⭐⭐ Medium+

Every project taught me something different. The key lesson from Employee_Records is how to combine multiple C concepts into a working program. Theory is easy — making it all work together is where real learning happens.
