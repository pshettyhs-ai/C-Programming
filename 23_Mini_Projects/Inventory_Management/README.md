# Inventory_Management

> **Author: Pavan Shetty H S**

## 📋 About This Project

A product inventory system for a small store. Manages stock levels, prices, low-stock alerts, and generates sales reports.

## 🔨 Compile and Run

```bash
gcc Source_Code/main.c -o program
./program
```

## 💡 Concepts Used

Structs, file I/O, sorting, searching, arithmetic

## ⭐ Difficulty: ⭐⭐⭐ Medium+

## 📁 Files

| File | What is inside |
|------|---------------|
| `Source_Code/main.c` | Complete program source code with comments |
| `Sample_Output/output.txt` | Example of what the program looks like when running |
| `Project_Report.md` | Design decisions, data model, complexity analysis |

## 🎯 What I Learned Building This

Every project taught me something different. The key lesson from Inventory_Management is how to combine multiple C concepts into a working program. Theory is easy — making it all work together is where real learning happens.
