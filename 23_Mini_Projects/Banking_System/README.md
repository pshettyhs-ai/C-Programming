# Banking_System

> **Author: Pavan Shetty H S**

## 📋 About This Project

A banking application that handles account creation, deposits, withdrawals, fund transfers, and transaction history. Each account maintains a log of its last transactions.

## 🔨 Compile and Run

```bash
gcc Source_Code/main.c -o program
./program
```

## 💡 Concepts Used

Structs, binary file I/O, pointer parameters, time.h, formatted output

## ⭐ Difficulty: ⭐⭐⭐ Medium+

| File | What is inside |
|------|---------------|
| `Source_Code/main.c` | Complete program source code with comments |
| `Sample_Output/output.txt` | Example of what the program looks like when running |
| `Project_Report.md` | Design decisions, data model, complexity analysis |

Every project taught me something different. The key lesson from Banking_System is how to combine multiple C concepts into a working program. Theory is easy — making it all work together is where real learning happens.
