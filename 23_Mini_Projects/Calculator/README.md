# Calculator

> **Author: Pavan Shetty H S**

## 📋 About This Project

A scientific calculator with support for arithmetic, trigonometry, logarithms, memory storage, and a history of recent calculations.

## 🔨 Compile and Run

```bash
gcc Source_Code/main.c -o program
./program
```

## 💡 Concepts Used

Functions, math.h library, switch-case, arrays for history buffer

## ⭐ Difficulty: ⭐ Easy

## 📁 Files

| File | What is inside |
|------|---------------|
| `Source_Code/main.c` | Complete program source code with comments |
| `Sample_Output/output.txt` | Example of what the program looks like when running |
| `Project_Report.md` | Design decisions, data model, complexity analysis |

Every project taught me something different. The key lesson from Calculator is how to combine multiple C concepts into a working program. Theory is easy — making it all work together is where real learning happens.
