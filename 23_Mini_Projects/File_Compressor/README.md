# File_Compressor

> **Author: Pavan Shetty H S**

## 📋 About This Project

A Run-Length Encoding (RLE) compressor and decompressor for text files. Demonstrates bitwise operations and binary file handling.

## 🔨 Compile and Run

```bash
gcc Source_Code/main.c -o program
./program
```

## 💡 Concepts Used

Bitwise operations, binary file I/O, string processing, algorithm design
