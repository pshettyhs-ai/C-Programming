# Library_Management

> **Author: Pavan Shetty H S**

## 📋 About This Project

A library book management system that tracks books, members, and borrowing records. Demonstrates linked list operations alongside file persistence.

## 🔨 Compile and Run

```bash
gcc Source_Code/main.c -o program
./program
```

## 💡 Concepts Used

Linked lists, structs, file I/O, dynamic memory, string search

## ⭐ Difficulty: ⭐⭐⭐ Medium+
