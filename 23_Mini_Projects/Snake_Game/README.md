# Snake_Game

> **Author: Pavan Shetty H S**

## 📋 About This Project

A classic terminal-based Snake game with score tracking, increasing difficulty, and game-over detection.

## 🔨 Compile and Run

```bash
gcc Source_Code/main.c -o program
./program
```

## 💡 Concepts Used

2D arrays, terminal I/O, game loop, structs for game state

## ⭐ Difficulty: ⭐⭐⭐⭐ Hard

| `Sample_Output/output.txt` | Example of what the program looks like when running |
