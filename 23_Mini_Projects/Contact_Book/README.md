# Contact_Book

> **Author: Pavan Shetty H S**

## 📋 About This Project

A personal contact manager that stores names, phone numbers, and emails. Supports search by name or number, alphabetical listing, and file persistence.

## 🔨 Compile and Run

```bash
gcc Source_Code/main.c -o program
./program
```

## 💡 Concepts Used

Linked lists, string searching, file I/O, dynamic memory

## ⭐ Difficulty: ⭐⭐ Medium

| File | What is inside |

| `Source_Code/main.c` | Complete program source code with comments |
| `Sample_Output/output.txt` | Example of what the program looks like when running |
| `Project_Report.md` | Design decisions, data model, complexity analysis |

Every project taught me something different. The key lesson from Contact_Book is how to combine multiple C concepts into a working program. Theory is easy — making it all work together is where real learning happens.
