# Student_Management

> **Author: Pavan Shetty H S**

## 📋 About This Project

A complete console-based student record system with add, view, search, update, delete, sort, and statistics features. Records are saved to a binary file so data persists between runs.

## 🔨 Compile and Run

```bash
gcc Source_Code/main.c -o program
./program
```

## 💡 Concepts Used

Structures, arrays of structs, binary file I/O, bubble sort, string functions, menu-driven design

## ⭐ Difficulty: ⭐⭐ Medium
