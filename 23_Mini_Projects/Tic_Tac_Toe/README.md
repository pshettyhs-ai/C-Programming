# Tic_Tac_Toe

> **Author: Pavan Shetty H S**

## 📋 About This Project

Tic Tac Toe with two modes: human vs human, and human vs computer. The computer uses the Minimax algorithm and cannot be beaten.

## 🔨 Compile and Run

```bash
gcc Source_Code/main.c -o program
./program
```

## 💡 Concepts Used

2D arrays, recursion, Minimax algorithm, game state management

## ⭐ Difficulty: ⭐⭐ Medium

## 📁 Files

| File | What is inside |
|------|---------------|
| `Source_Code/main.c` | Complete program source code with comments |
| `Sample_Output/output.txt` | Example of what the program looks like when running |
| `Project_Report.md` | Design decisions, data model, complexity analysis |

Every project taught me something different. The key lesson from Tic_Tac_Toe is how to combine multiple C concepts into a working program. Theory is easy — making it all work together is where real learning happens.
