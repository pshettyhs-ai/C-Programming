# 05_Conditional_Statements — Conditional Statements

> **Author: Pavan Shetty H S**

## 📋 What This Chapter Covers

Making decisions in code. This chapter covers if, else if, else, switch-case, and the ternary operator. I highlight the common mistakes beginners make — especially the dangling else problem and forgetting break in switch.

By the end of this chapter you should be comfortable with every core concept, be able to write correct programs without looking at a reference, and confidently answer interview questions on this topic.
