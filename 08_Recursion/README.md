# 08_Recursion — Recursion

> **Author: Pavan Shetty H S**

## 📋 What This Chapter Covers

A function that solves a problem by calling itself on a simpler version of it. The concept is elegant but tricky to get right. I walk through base cases, call stack visualisation, classic problems, and how to fix exponential recursion with memoization.

## 🎯 Learning Goals

By the end of this chapter you should be comfortable with every core concept, be able to write correct programs without looking at a reference, and confidently answer interview questions on this topic.
